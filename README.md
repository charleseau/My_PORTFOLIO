Featured Portfolio Artifacts
This repository contains real, production-grade program management templates and samples developed from experience delivering enterprise programs in regulated environments.

Project Charter (Enterprise System Implementation)
A comprehensive project charter template modelled on large-scale financial services delivery. Includes scope definition, governance structure, stakeholder matrix, RACI, success criteria, and delivery milestones.
"A strong charter is the single most important document in any program. It aligns the room before a line of code is written."

Risk & Issue Log
A structured risk and issue register built for multi-vendor, cross-functional programs. Includes probability/impact ratings, ownership, mitigation plans, and escalation thresholds, following enterprise risk frameworks used in financial services delivery.

Stakeholder Communication Plan
A complete stakeholder engagement and communication strategy template. Covers identification, influence/interest mapping, engagement cadence, escalation paths, and communication channel design, built for programs with internal business, technology, and external vendor stakeholders.

Program Budget Tracker
A budget planning and reporting template for programs with multi-vendor cost streams. Tracks planned vs. actual by workstream, manages contingency, handles vendor invoice milestones, and produces executive-ready cost summaries.
